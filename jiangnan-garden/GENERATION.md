# 江南体素园林生成记录

这个目录保存一座可交互的江南古典园林体素小景。作品入口是 [index.html](index.html)，为包含 Three.js 渲染代码的单文件静态页面，无需构建或联网加载素材。

## 模型与实现

园林场景由 JavaScript 程序化生成体素几何体，不依赖外部图片或 3D 模型资源。页面使用 Three.js 0.158.0 进行实时渲染，其许可见 [licenses/three-MIT.txt](licenses/three-MIT.txt)。

场景包含矩形围墙院落、粉墙黛瓦房屋、月洞门、莲池、九曲石桥、竹林、桃花树、假山、亭台与石桌摆件。切换时段时，背景、环境光和定向光渐变，阴影随主光源移动。园路按同一网格铺设石板，在路口和转角保持同一铺装高度和接缝。

## 打开与操作

使用支持 WebGL 的现代浏览器直接打开 [index.html](index.html)。

- 右上角可选「清晨」「正午」「夜晚」，初次打开是正午。
- 点按正屋木门，门扇会打开或合上。每次点按莲池水面会泛起一圈涟漪，锦鲤空闲时有 30% 概率触发跃水。系统启用减少动态效果时，水面会短暂显示静止的波纹。
- 五盏石灯分布在入口、正屋前、两侧桥头和亭前。它们默认白天熄灭、入夜亮起。点按任意一盏可单独开关，手动设置会在本次游览的时段切换中保留。
- 左侧控制面板支持左转 15°、右转 15°、归正 90°、回到正面、视角上抬、视角下俯与默认俯仰七项操作。
- 鼠标左键拖拽可旋转和俯仰，右键拖拽时画面从当前位置跟随鼠标上下左右移动，滚轮可缩放。

## 验证

在仓库根目录运行 `node --test tests/jiangnan-garden.test.mjs`，可验证时段过渡、木门开合、拖拽与点击区分、莲池互动、石灯状态及铺装接缝。
