# 江南体素园林生成记录

这个目录保存一座可交互的江南园林小景。作品入口是 [index.html](index.html)。它是单文件静态页面，内含 Three.js 运行代码，不需要构建或联网加载素材。

## 使用的模型

本次由 **Codex（基于 GPT-6）** 编写场景、界面和交互代码，并用浏览器检查效果。当前会话没有提供可核验的具体模型变体 ID 或推理参数，因此不标注 Astra、Sol 等子型号。作品没有调用图像生成模型；园林由 JavaScript 创建的体素几何体组成。Three.js 0.158.0 是页面使用的 3D 渲染库，不是生成模型，其许可见 [licenses/three-MIT.txt](licenses/three-MIT.txt)。

## 用户提示词

最初的生成要求如下，保留原文：

> 做一个精致的体素风格的江南古典园林小景：矩形围墙院落里有包括但不限于粉墙黛瓦的房屋、月洞门、莲池、石桥、竹林、桃花树、假山和亭台等等，布局尽量按图还原，浅灰背景、相机默认俯视。左侧一块信息面板，有左转 15°、右转 15°、归正 90°、回到正面、视角上抬、视角下俯、默认俯仰七个按钮；鼠标拖拽旋转和俯仰、右键平移、滚轮缩放。生成html文件

随后用户提出一次画面修订，原文如下：

> 加入适当的光照和阴影, 增加精致感, 地面加入花草

最初要求提到“按图还原”，但会话中没有收到参考图。因此当前布局按文字要求设计，不能视为对某张图片的精确复刻。

## 打开与操作

前置条件：使用支持 WebGL 的现代浏览器。直接打开本目录的 `index.html` 即可，不需要本地服务器。

左侧七个按钮控制水平角度和俯仰角度。其中“归正 90°”将水平视角对齐到最近的 90° 方位，“回到正面”恢复正面方位并重置平移与缩放。左键拖拽可旋转和俯仰，右键拖拽可平移，滚轮可缩放。

## 实现与验证

场景包括围墙、房屋、月洞门、莲池、石桥、竹林、桃花树、假山、亭台和地面花草。柔和环境光与带阴影的定向光负责表现建筑和树木的层次。花草使用实例化几何体绘制，减少重复对象的渲染开销。

交付前已在桌面 1440×900 和手机 390×844 的浏览器视口检查画面。浏览器检查确认有七个视角按钮，抽查的按钮、左键拖拽和滚轮操作会改变画面；未发现脚本错误，手机宽度下没有水平溢出。另检查到阴影渲染已开启，场景包含投影与接影对象，以及实例化的草和花。右键平移等未逐项做自动化断言，不把这次检查视为所有交互环境的完整验收。
