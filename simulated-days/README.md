# 模拟时光

《模拟时光》是一款可在浏览器里玩的单人生活模拟。玩家陪年轻创作者 Miri 住在原创街区“紫蓝巷”，照顾五项日常状态，布置小屋，并认识三位邻居。

生成过程、用户提示词和模型说明见 [GENERATION.md](GENERATION.md)。

## 运行

前置条件：Python 3、支持 WebGL 的现代浏览器，以及完整仓库目录。页面使用 `second-room/vendor/` 中的本地 Three.js 文件，不能只复制 `simulated-days/` 目录单独部署。

在仓库根目录执行：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/simulated-days/`。页面使用 ES 模块，不能直接通过 `file://` 打开。运行时不请求外部图片、字体或游戏服务。

## 操作

- **生活模式**：点击小厨房、画桌、床、浴室、书架或茶桌，选择互动。做饭、画画和聊天会完成当天的三个“微小日常”。画画带来收入与创作经验；做饭提高烹饪经验。
- **建造 / 购买**：在右侧购买家具。点击已拥有的家具，再点击房间地板，家具会移动到网格位置。初始的绿植和地毯也可以移动。
- **社区浏览**：在地图上查看地点，在右侧邻居卡片点击“聊天”。关系值和社交状态会变化。
- 在房间中拖动鼠标旋转视角，用滚轮或右下角按钮缩放。右下角也有旋转和重置视角按钮。

互动会推进游戏内时间，同时逐渐消耗状态。精力或暖光币不足时，操作会显示原因，不会扣除资源。每次有效操作都会更新顶部货币、状态、技能或关系，并写入“最近发生”。

## 存档与限制

进度在每次有效操作后自动写入浏览器的 `localStorage`，页面右侧或页脚会显示保存状态。刷新页面可继续游玩。存档只在当前浏览器与当前站点地址下有效；清除浏览器站点数据会删除存档。浏览器禁止本地存储时，页面会提示无法保存。

这是一个舒缓节奏的静态游戏原型。时间仅在玩家操作时推进；家具使用五乘五的摆放网格，暂不做碰撞校验。人物和街区均为原创程序绘制模型与插画。Three.js 的许可见 [`../second-room/vendor/LICENSE-three.txt`](../second-room/vendor/LICENSE-three.txt)。

## 检查

在仓库根目录执行：

```sh
node --test simulated-days/tests/game.test.mjs
node --check simulated-days/app.mjs
node --check simulated-days/game.mjs
```
