# 模拟时光生成记录

《模拟时光》是一款浏览器中的单人生活模拟。游戏入口是 [index.html](index.html)，运行方法和操作说明见 [README.md](README.md)。

## 使用的模型与工具

本次由 **Codex（基于 GPT-6）** 编写游戏规则、三维场景、界面和测试，并在浏览器中检查交互。当前会话没有提供可核验的具体模型变体 ID 或推理参数，因此不标注 Astra、Sol 等子型号。

没有调用图像生成模型，也没有使用外部生成的角色或家具图片。Miri、小屋和家具由 JavaScript 几何体绘制；街区地图和界面图标由页面内的 SVG 绘制。页面使用仓库已有的 Three.js 0.186.1 文件进行三维渲染。Three.js 是渲染库，不是生成模型，许可见 [../second-room/vendor/LICENSE-three.txt](../second-room/vendor/LICENSE-three.txt)。开发时参考了本地 UI/UX 设计规范，检查文字可读性、键盘焦点、响应式布局和减弱动画设置。

## 实现范围与验证

游戏包含生活、建造 / 购买和社区浏览三个入口。玩家操作会推进游戏内时间、改变五项状态，并更新货币、技能、关系和每日目标。家具可在五乘五网格中重新摆放；进度在每次有效操作后写入当前浏览器的 `localStorage`。时间不会在玩家不操作时自行流逝，家具摆放暂不检查碰撞。这些限制也写在 [README.md](README.md) 中。

交付前运行 `node --test simulated-days/tests/game.test.mjs`，7 项测试通过；`node --check` 检查两个游戏模块，`git diff --check` 无报错。浏览器中验证了做饭、创作、购买并移动家具、邻居聊天、视角旋转与缩放，以及刷新后的存档恢复。375px 和 1440px 视口没有横向溢出。测试产生的存档已清除，试玩页恢复到第 1 天、320 暖光币。
