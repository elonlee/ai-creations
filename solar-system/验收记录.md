# 太阳系网站验收记录

## 实现顺序

场景 → 交互 → UI → 动效 → 验收。场景先建立真实彩色贴图、光照与轨道；交互随后接入目标跟踪、时间和图层状态；再完成黑白像素界面、开场与过渡，最后做桌面和手机实测。

## 实测结果

| 项目 | 结果与证据 |
| --- | --- |
| 静态运行 | 从本目录运行 `python3 -m http.server 8765`，浏览器加载 `http://localhost:8765/`。入口使用本地 importmap 和 ESM。一次新页面加载记录到 22 个响应，没有外域请求，也没有 HTTP 400 以上响应。无需构建与后端。 |
| 开场 | 新加载即出现月面 Bayer 抖动图。资源准备期间按钮禁用并显示进度；资源可用后仍停留在开场，点击“开始探索”才退场。普通模式播放标题淡出和斜向像素波，减少动态效果模式直接进入。 |
| 总览 | 点击后显示太阳、轨道线、行星标签和十个天体的目录。太阳位于轨道中心。 |
| 十天体 | 依次用 `1–0` 选中太阳、水星、金星、地球、火星、木星、土星、天王星、海王星、月球。目录选中态、底部英文名与铭牌对应；逐个截图核对贴图显示。天体使用彩色真实影像，水星与月球的灰色来自原素材。浏览器控制台没有 shader 编译错误。 |
| 相机与点选 | 4× 速度下聚焦地球并持续观察，目标保持在画面内。点击画布太阳可射线选中；经纬度读数随指向更新。预设“明暗交界”可选中并更新操作日志。 |
| 地球图层 | 分别关闭表面、云、大气、夜间灯光，按钮状态与渲染同步。四项全部关闭后球体显著变为平灰；重新加载可恢复默认图层。夜侧可见暗面与城市灯光。云层与地表共用自转角度；关闭自转后两层一起停止。 |
| 土星与月球 | 土星本体及环在同一倾斜组，环随赤道倾斜。月球加载 LRO 灰色影像，近景未出现白色泛光。月球高清与极清文件分别由官方 8K 源图生成。 |
| 画质 | 标准、高清 4K、极清 8K 三档切换后均可继续操作。缺少高档原图的天体按清单回退，不产生 404；高档只给当前聚焦天体加载，避免同时占用大量显存。 |
| 桌面布局 | 1440×900 截图核对目录、铭牌、工具栏、详情面板。详情打开时工具栏左移，没有被面板覆盖；页面没有横向溢出。 |
| 手机布局 | 390×844 截图核对横向目录、铭牌、两行工具栏、底部面板及操作日志。页面没有横向溢出，步进器可见，面板止于工具栏上方。 |
| 可访问性与键盘 | 选中与开关的 ARIA 状态随操作变化。`Esc` 关闭设置面板后焦点返回触发按钮。减少动态效果模拟下，开场退场和天体标题直接切换。 |
| 控制台与文件 | 最终浏览器 `error`、`warn` 日志为空。从本目录执行 `node --check app.mjs` 通过；`node --test tests/logic.test.mjs` 五项通过，其中新增云层与地表同步测试。 |

## 边界

场景为了同时看清行星，缩放了天体尺寸、轨道半径和运动速度。它不是实时星历。天王星和海王星的原始素材只有 2K；金星云层最高为 4K。对应档位会使用可获得的最高原图，不把低分辨率图冒充 8K。月面来自 NASA LRO 原图，行星贴图与地球蓝色海洋来自 Solar System Scope；具体链接和授权写在 [README.md](README.md)。
