## 生成提示词

主提示词由用户用中文提出。下面按原需求整理其关键内容，便于以后复现；这不是逐字聊天记录。

> 完整实现一个黑白像素风的交互式太阳系网站。网站必须是纯静态的：`index.html` 入口、importmap、原生 ESM、本地 three.js 与全部依赖，不使用 CDN、构建步骤或后端。太阳、八大行星和月球必须是实时 3D；几何体使用 three.js，贴图使用 NASA Visible Earth、LRO 月图和 Solar System Scope 的真实天文影像，并按标准、4K、8K 档组织。实现日夜地球、城市灯光、独立云层和大气、共面倾斜的土星环、潮汐锁定的月球，以及固定稀疏星点。
>
> 实现目录与射线点选、上一颗和下一颗、持续跟踪目标的平滑聚焦镜头、六类观察机位，以及暂停、自转、公转、速度、轨道线、标签和重置控制。界面采用黑白灰像素风：顶栏、分组天体目录、左下铭牌、底部工具栏、详情和设置面板、日志与经纬度十字线。开场使用月面 Bayer 有序抖动，必须点击才进入，并有像素波退场。支持键盘、手机布局、可访问性和减少动态效果设置。
>
> 按“场景 → 交互 → UI → 动效 → 验收”的顺序实现，并在桌面 1440×900、手机 390×844 下检查显示、控制台、素材请求和十个天体的切换。交付可本地运行、可放到静态托管的完整文件，不使用占位素材或虚构数据。

开发过程中，用户又给出两条直接影响最终结果的修订提示词：

1. “黑白像素仅限于UI, 星球不要仍然用黑白像素, 使用真实颜色”。因此黑白像素效果只用于界面与开场；球体使用真实颜色的天文贴图。
2. “这个贴图云层转动的好像有点问题. 是不是不转更好”。因此地球云层不再独立滑动，而是与地表同步自转；关闭“自转”时两层一起停止。

## 交付与复现

在本目录执行 `python3 -m http.server 8765`，然后打开 `http://localhost:8765/`。浏览器需要通过本地 HTTP 服务加载 ESM；直接用 `file://` 打开可能受到模块加载限制。将本目录完整复制到静态托管目录即可部署。

场景半径、轨道距离和运行速度经过展示性调整，不是实时星历。天王星和海王星只有可用的 2K 原始贴图；画质选择会回退到实际可用的素材，不把放大图标作原生 8K。
