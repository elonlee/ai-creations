# 太阳系网站的生成记录

这是一个纯静态 Three.js 太阳系观测网站。入口是 [index.html](index.html)，运行方法、素材来源和授权见 [README.md](README.md)，功能实测见 [验收记录.md](验收记录.md)。

## 架构与素材处理

- **纯静态架构**：使用原生 ESM 与 `importmap` 加载本地 `three.js` 与依赖，无 CDN、构建步骤或后端。
- **实时三维与天文影像**：太阳、八大行星与月球使用真实天文影像（NASA Visible Earth、LRO 月图与 Solar System Scope）按标准、4K 与 8K 档按需加载；包含日夜地球、城市灯光、同步自转的独立云层与大气、共面倾斜土星环、潮汐锁定月球与稀疏星点；天王星与海王星因官方最高仅提供 2K 源图而保持标准档。
- **黑白像素风 UI**：黑白灰像素与 Bayer 有序抖动仅用于界面、开场月面与退场转场；天体本身保留真实彩色纹理。
- **交互与可访问性**：实现目录与射线点选、平滑聚焦镜头、六类观察机位、速度/自转/公转/轨道/标签控制，并支持键盘快捷键、手机布局、ARIA 状态与 `prefers-reduced-motion`。

## 交付与复现

在目录内执行 `python3 -m http.server 8765` 并打开 `http://localhost:8765/` 即可本地运行，完整目录可直接用于静态托管。场景半径、轨道距离与运行速度经过展示性调整，不作为实时星历推算依据。
