# Cat Music 静态播放器

这是从 [gamdl-player](https://github.com/elonlee/gamdl-player) 的前端界面改写出的独立静态演示。页面保留了资料库分类、专辑网格、右侧专辑详情、专辑大图和播放控制。所有数据在本地 JavaScript 文件中，不连接 Apple Music 或原项目的 FastAPI 服务。

四张专辑和十二首歌曲用于展示界面。其中十首歌曲及对应艺人是虚构信息，不能播放。两首标注“真实录音 · CC0”的歌曲有本地 MP3，可以试听。素材来源和制作记录见 [GENERATION.md](GENERATION.md)。

## 运行

前置条件是 Python 3 和现代浏览器。在 `ai-creations` 仓库根目录执行：

```sh
python3 -m http.server 8767
```

打开 `http://localhost:8767/cat-music-demo/`，预期会看到专辑网格。点击“开放录音选集”可以查看两首可试听曲目。页面使用 ES 模块，建议经 HTTP 服务打开，不要直接用 `file://` 打开 HTML 文件。

## 操作

- 在左侧分类切换歌曲、专辑、艺人和收藏；手机上分类显示为横向导航。
- 搜索框支持按歌曲、专辑和艺人名称筛选。点击专辑会从右侧打开详情；按 Esc、点“返回专辑列表”或点遮罩可以关闭，列表位置保持不变。
- 点击顶部当前歌曲的小封面，或专辑详情中的“查看专辑大图”，可以打开大图。真实录音的大图页有播放控制和四种可切换的视觉特效。再次切换可关闭特效；暂停播放时动画停止。示例专辑只显示大图和说明。
- 点真实录音旁的播放按钮，或使用顶部播放、上一首、下一首、进度和音量控制。浏览器要求用户先主动点击，页面不会自动播放。
- 点心形按钮收藏歌曲。收藏与深色模式保存在当前浏览器的 `localStorage`；清除网站数据后会重置。

示例歌曲旁显示“仅展示”，没有音频文件。播放特效是随播放状态变化的装饰动画，不根据音频频谱生成。播放器中的两首真实录音与原项目的 Apple Music 下载内容无关。此页面不提供下载、扫描、本地音乐库导入或账户功能。

## 本地检查

在仓库根目录执行：

```sh
node --test cat-music-demo/tests/*.test.mjs tests/gallery.test.mjs
node --check cat-music-demo/app.mjs
node --check cat-music-demo/model.mjs
```

测试会检查示例资料关联、音频文件、搜索、切歌和作品集入口。浏览器中的播放与响应式布局仍需从本地 HTTP 服务打开检查。
