# 山水有归处 · 重装版（v2）

在保留原版 [`ink-scroll-book`](../ink-scroll-book/README.md) 的基础上，对交互体验、视觉层次与阅读仪式感进行整体重装的浏览器活水墨全景长卷电子书。

## 重装亮点

1. **连续活水墨全景画布（`ink-stage.mjs`）**
   - 六段章节（入卷、听雨、过桥、寻山、归舟、跋）不再是静止分屏，而是随滚动在三幅原画之间平推镜头与柔雾叠化。
   - Canvas 实时绘制山谷游云、斜织春雨、飞瀑水雾、远飞墨鸟、暮江残阳波光与芦絮；轻点纸面或水面可荡开水墨涟漪。
2. **三种阅读仪态（右上工具栏 / 快捷键）**
   - **夜读松烟（`N`）**：切换晴昼宣纸与月夜墨色，暗化天色而保留墨山剪影，归舟旁泛起微暖渔火。
   - **竖排乌丝栏（`V`）**：将正文排版切换为宋刊线装竖排与乌丝栏细格。
   - **净卷赏画（`P` / `Esc`）**：收起文字与导览，将三幅画作拼接成一幅连续长卷，支持鼠标拖拽、滚轮横览、1×–2.1× 缩放与缩略舆图点选跳转。
3. **古琴七弦与山川声景（`music.mjs`）**
   - 保留原版两首开放授权古琴实录（《阳关三叠》《醉渔唱晚》），新增下方七根可轻拨试音的五声音阶丝弦。
   - 新增「声景」开关，采用 Web Audio 实时合成随章节流转的细雨敲竹、松风过壑与江水轻拍（默认关闭，需手动开启）。
4. **过桥画境细观、眉批与自题钤印留笺（`reader.mjs`）**
   - 「过桥」可点选柳岸细雨、石桥拱影、雾中白墙三处局部聚焦赏析；各幕可展开朱红「眉批」。
   - 「跋」末尾提供「余墨自题 · 钤印留念」，可自定 1–4 字印文、切换朱文/白文印式、书写个人题跋并钤印保存至本地，还可一键裁卷导出 `1200×1800` 高清留笺 PNG 书签。

## 本地阅读与测试

在**仓库根目录**运行：

```sh
python3 -m http.server 8767
```

打开 `http://localhost:8767/ink-scroll-book-v2/`。页面复用 `../ink-scroll-book/assets/` 下的本地水墨插画与古琴 MP3 录音，无需联网。

运行自动化测试：

```sh
node --test ink-scroll-book-v2/tests/*.test.mjs
```
