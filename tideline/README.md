# 潮汐之间

一个四幕滚动叙事落地页。全屏 Canvas 实时绘制天空、日轮、起伏的潮位、三层移动波浪与漂浮光点。向下滚动时，画面颜色、海平线、波浪强度和光源位置会随“启程、遇光、入海、归来”连续变化。文字和导航保留在 HTML 中，可以用键盘访问。

## 本地运行

前置条件：安装 Python 3，使用支持 Canvas 2D 和 ES Modules 的现代浏览器。

在仓库根目录运行：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/tideline/`。预期会看到“听见海的呼吸”首屏；滚动或点击章节导航，可以进入其余三幕。页面没有外部字体、图片或脚本请求，断网后仍可从本地 HTTP 服务打开。

运行叙事过渡测试：

```sh
node --test tideline/tests/scene.test.mjs
```

浏览器启用“减少动态效果”时，背景停止持续动画，但滚动仍会切换场景。若 Canvas 不可用，深色背景和完整叙事文字仍可阅读。

提示词、制作方式和验证范围见 [GENERATION.md](GENERATION.md)。
