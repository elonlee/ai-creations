# 《潮汐之间》制作说明

这是一页无需构建步骤的静态落地页。入口是 [index.html](index.html)。所有可见画面由浏览器 Canvas 2D 和 CSS 实时绘制，项目没有生成或引入图片、音频等外部素材。

## 用户提示词

> 做一个实时渲染背景的沉浸式落地页。全屏画布之上，四段叙事随滚动展开。

## 模型与实现

本次由 Codex（基于 GPT-6）编写页面、绘制代码、文案、测试和说明。当前会话没有可核验的具体模型变体 ID 或推理参数，因此不标注子型号。页面运行时不会调用 AI 模型或远程 API。

`scene.mjs` 定义四幕的颜色、海平线、光源、波浪强度与水下光晕参数，并按滚动位置插值。它也计算缓慢变化的潮位和随时间移动的波峰。`app.mjs` 每帧绘制天空渐变、日轮、星点、三层有明暗面的波浪和微光；同时更新章节导航。`style.css` 负责排版、窄屏布局和减少动态效果时的静态呈现。

## 验证

在仓库根目录运行 `node --test tideline/tests/scene.test.mjs`，检查四幕边界、连续过渡、水下光晕淡入淡出、潮位范围与波峰位移。使用本地 HTTP 服务在浏览器检查 375 像素和 1440 像素宽度、章节跳转及横向溢出。画面的实际帧率取决于设备和浏览器，没有固定帧率保证。
