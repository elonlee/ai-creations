# 《潮汐之间》制作说明

这是一页无需构建步骤的沉浸式静态落地页，随滚动展开四幕叙事。入口是 [index.html](index.html)。所有可见画面均由浏览器 Canvas 2D 与 CSS 实时绘制，未生成或引入外部图片、音频素材。

## 实现结构

- [scene.mjs](scene.mjs)：定义四幕天空色彩、海平线、光源、波浪强度与水下光晕参数，并按滚动位置插值；同时计算缓慢变化的潮位与波峰位移。
- [app.mjs](app.mjs)：每帧绘制天空渐变、日轮、星点、三层明暗波浪与微光，并同步章节导航与进度条。
- [style.css](style.css)：负责排版、窄屏适配与 `prefers-reduced-motion` 静态呈现。

## 验证

在仓库根目录运行 `node --test tideline/tests/scene.test.mjs`，检查四幕边界、连续过渡、水下光晕淡入淡出、潮位范围与波峰位移。此前已通过本地 HTTP 服务在 375px 与 1440px 视口检查章节跳转与无横向溢出；实际帧率取决于设备性能。
