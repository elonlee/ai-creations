# 《还剑渡》第一章

这是一个可在浏览器里游玩的武侠 RPG 第一章。陆照从荒山驿道进入乌篷渡，调查赈粮旧案，最后在码头与程砚交手。游戏包含四处探索场景、剧情对话、驿道随机遭遇、回合制战斗和经验升级。

## 运行

在仓库根目录 `/Users/elon/mycodes/ai-creations` 执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/huanjian-du/`。主界面提供“开始游戏”和“游戏说明”两个选单。选择“开始游戏”后，黑屏字幕会交代赈粮旧案和陆照此行的缘由，再进入驿道。字幕每段自动播放约 3.4 秒，也可以点“继续”逐段阅读或点“跳过剧情”直接进入游戏。选择“游戏说明”可查看操作和规则，再返回主界面。页面使用原生 HTML、CSS 和 JavaScript，不需要安装前端依赖。请通过本地 HTTP 服务访问，直接打开 `index.html` 不能加载 ES 模块。

## 操作与规则

方向键或 WASD 移动，靠近金色标记后按空格交互。鼠标和触屏可使用页面右侧的方向与交互按钮。对话使用当前场景作背景，陆照和 NPC 的放大立绘分列左右，完整显示在底部半透明文字框上方。点击文字框逐句阅读，也可按 Enter 或空格。驿道流民会先交谈，再让玩家选择交出口粮、答应调查或拔剑。程砚会在码头先与陆照对质，对话结束后进入决战。驿道会随机遇到山贼，短时间内不会连续触发遭遇；其余场景没有随机战斗。

战斗界面左上角显示陆照的等级、经验、气血和内力；右上角显示对手气血与下一招提示。战斗中按数字 1～5 或点击指令：出剑、破招、守势、用药、退走。破招消耗 2 点内力，可打断对手的蓄势招式；守势减伤并恢复 1 点内力；金疮药恢复 16 点气血。普通遭遇可以尝试退走，码头剧情战不能退走。气血耗尽后可以重新开始。

陆照从 1 级开始。调查首次发现的关键线索、和平帮助流民，以及战胜山贼或程砚，都会获得经验。累计经验达到 20、55、105 点时依次升到 2、3、4 级；之后门槛继续提高。每升一级，气血上限增加 6、内力上限增加 1，出剑和破招伤害增加 2。角色面板显示当前等级、累计经验和下一等级门槛；重复调查同一条线索不会重复获得经验。

## 当前范围

场景使用概念图作为背景，并叠加逻辑格点、可通行区域和交互点。它还不是由地图图块、逐格碰撞层和 NPC 行走逻辑组成的正式地图。流民事件中，主动动武会与藏在其后的山贼交战；目前没有流民的独立战斗素材。当前进度仅保存在打开的页面内，刷新会返回主界面；暂未制作存档、音效和更多章节。

[场景设计](SCENES.md)、[战斗设计与动作预览](BATTLE.md)和[素材生成记录](GENERATION.md)保留了本章的设计与素材来源。

在仓库根目录运行 `node --test huanjian-du/tests/*.test.mjs` 可检查探索、剧情、升级、战斗和动画规则。图片帧测试需要 `uv` 与 Pillow：`uv run --with pillow python -m unittest discover -s huanjian-du/tests -p 'test_battle_frames.py'`。
