# AI 小作品

这里存放我借助 AI 制作的一些小东西，主要用于个人学习和测试。项目内容会随尝试逐步增加。

## 浏览作品首页

根目录的 [index.html](index.html) 用缩略图卡片展示 14 个作品入口。前置条件是 Python 3 和现代浏览器。在仓库根目录运行：

```sh
python3 -m http.server 8767
```

打开 `http://localhost:8767/`，预期会看到按屏幕宽度排列的作品卡片。点击整张卡片即可进入对应作品。首页缩略图的制作与素材来源见 [GALLERY.md](GALLERY.md)。

以后每新增一个项目，都要在同一次修改中更新根目录的 [index.html](index.html)：添加指向项目入口的缩略图卡片，写清标题、类别和简介，并提供本地缩略图。同步更新首页显示的作品总数、卡片编号，以及下方的作品列表。完成后检查新链接可以打开，手机和桌面布局没有溢出。
